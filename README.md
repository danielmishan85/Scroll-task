# TV Shows Search

A React and Express application for searching TV shows using the TVmaze API.

https://github.com/user-attachments/assets/66ec183a-5383-4125-aafe-9e3f90f4069c

## Run locally

### Requirements

- Node.js 22.6 or newer
- npm

### 1. Install dependencies

From the project root:

```bash
npm install
```

### 2. Start the API server

In the first terminal:

```bash
node src/server.ts
```

The API runs at `http://localhost:3000`.

### 3. Start the client

In a second terminal, from the project root:

```bash
npm run dev
```

Open `http://localhost:5173` in your browser.
